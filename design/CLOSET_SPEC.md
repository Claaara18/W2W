# Closet 松鼠實作規格（給 Claude Code）

參考稿：`design/closet-match-proto.html` 裡的 `addFlow()`（新增單品時松鼠在上傳視窗裡思考）。只參考樣子與節奏，**不要搬程式碼**。
要改的檔案：`components/Squirrel.js`、`screens/ClosetScreen.js`

## 全 App 的松鼠原則（這份與之後的頁面都適用）
- 每個主要分頁都可以有松鼠，但**平常安靜**：固定站在標題旁或卡片上，只眨眼、搖尾巴、呼吸；**不閒晃、不在頁面上跳來跳去**。
- 只在**完成一件事**時表演（思考 → 開心）。
- Home 維持現在的完整版，不要改動 Home 的行為。
- Match 頁不放松鼠。
- 松鼠永遠不能擋住點擊；離開頁面時暫停（沿用 `paused={!isFocused}` 的做法）。
- 不做 `+1 acorn`、橡果數量等計分。

## 第 0 步：Squirrel 元件加兩個 props（不影響 Home）
- `scale`（預設 `1`）：整隻松鼠等比縮放，其他頁用 `0.6～0.75`。
- `quiet`（預設 `false`）：`true` 時不做閒晃小跳、不做隨機快速搖尾巴；眨眼、呼吸、睡覺照常。
- Home 不傳這兩個 props，行為必須和現在完全一樣。

## 第 1 步：去背時由松鼠陪著（取代現在的「去背中 n/N」文字框）
現在 `processAndAdd` 會顯示 `ProcessingOverlay`（轉圈＋文字）。改成：
1. 半透明遮罩中央是一張奶油色圓角卡片，卡片裡是一隻松鼠（`scale` 約 0.8，固定不移動）。
2. 開始處理第 i 張時：松鼠 `think([這張照片的 uri])`，頭上泡泡顯示**正在處理的那張照片**；卡片下方文字「去背中 i/N…」。
3. 每張成功：松鼠小跳一下（`celebrate(1, { haptic: false })`），換下一張再 `think`。
4. 每張失敗（會改存原圖）：不跳，直接換下一張；結束後照舊顯示「部分照片未去背」提示。
5. 全部完成：`celebrate(2, { confetti: true })`，約 1 秒後遮罩淡出。
6. 等待時間**完全跟著實際去背**，不要額外加假的等待；也不要因為等動畫而延後把衣服加進衣櫃。
7. 不要改 `prepareImage`、`removeBackground`、`keepOriginal`、`addItem` 的邏輯，只換畫面。

## 第 2 步：Closet 首頁的安靜松鼠
- Closet 列表頁標題「Closet」右側、愛心按鈕左側，放一隻 `quiet`、`scale` 約 0.6 的松鼠，腳踩在標題底線上方。
- 點牠：輪流 happy／acorn 跳一下（沿用現有行為）。
- 抽屜內頁、Collection 頁**先不放**（Collection 之後會改版）。

## 完成標準
- 一次選 3 張照片：遮罩裡松鼠泡泡依序顯示每一張，成功時小跳，最後噴彩帶後遮罩消失；衣服都有加進衣櫃。
- 斷網或額度不足時：照片照樣以原圖加入，松鼠不會卡在思考狀態，遮罩會正常消失。
- Home 的松鼠行為與之前完全相同。
